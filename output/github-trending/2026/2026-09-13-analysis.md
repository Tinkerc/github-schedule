# GitHub Trending AI 分析报告

> 分析日期: 2026-09-13

---

## 1. 趋势概览
今日GitHub热榜中AI类项目占比超60%，是绝对主流方向，同时网络工具、地理空间智能、媒体工具类项目也有较高关注度。突出的技术方向包括：大模型垂直场景Agent落地爆发、AI原生开源商业工具替代潮、头部大模型底层Prompt设计研究热度飙升、平民化空间智能工具涌现、用户数字访问自主权需求上升。

## 2. 热门项目分析
### ① asgeirtj/system_prompts_leaks（⭐65.6k）
**特点**：全网最全的头部大模型官方系统提示词合集，覆盖Anthropic、OpenAI（含未正式公开的GPT-6 Astra）、Google、xAI、Kimi等主流厂商的最新模型，持续更新。
**价值**：首次公开了头部厂商大模型对齐、角色设定、能力边界设计的核心逻辑，是Prompt工程和大模型对齐研究的一手权威资料。
**应用场景**：Prompt工程师学习最佳实践、开源大模型系统提示词优化、AI安全研究人员分析模型对齐漏洞。

### ② bilawalsidhu/gods-eye-view（⭐30.5k）
**特点**：纯浏览器端运行的 photorealistic 3D地球空间情报工具，所有卫星数据均为真实实时数据，无需安装专业GIS软件即可使用。
**价值**：将原本仅面向政府、专业机构的空间情报能力平民化，普通用户零门槛即可获取全球地理空间动态。
**应用场景**：开源情报（OSINT）调查、应急救灾态势感知、地理学科教育、跨境项目选址调研。

### ③ jihe520/MathModelAgent（⭐5.2k）
**特点**：国内开发者推出的专属数学建模场景的AI Agent，内置建模、数值求解、论文排版等全套定制技能，可直接输出符合国内外建模竞赛规范的可提交完整论文。
**价值**：大幅降低数学建模参赛门槛，可节省90%以上的建模和论文写作时间，填补了垂直学术场景Agent的落地空白。
**应用场景**：大学生数学建模竞赛、科研项目的数学建模环节、高校建模课程教学辅助。

### ④ melgarafael/DeskcommCRM（⭐1.9k）
**特点**：AI原生的开源销售CRM，内置原生AI Agent、WhatsApp集成（基于WAHA），支持多租户、LGPD合规、MCP协议，可完全自托管。
**价值**：是商用聊天销售CRM（Kommo、Octadesk、Intercom）的完美开源替代，中小微企业可零成本搭建AI驱动的私域销售体系，数据完全自主可控。
**应用场景**：跨境电商客户管理、外贸私域运营、中小服务商的销售流程自动化。

## 3. 技术趋势
1. **大模型Agent进入垂直深耕阶段**：从通用聊天Agent转向数学建模、交易、网络安全、音乐生成等细分场景，技能高度定制化，落地价值大幅提升，成为当前AI落地的核心路径。
2. **AI原生开源SaaS替代潮兴起**：大量瞄准商用AI SaaS痛点的开源工具出现，支持自托管、数据可控、成本极低，正在快速冲击商用SaaS的中小客户市场。
3. **大模型底层设计研究成显学**：头部大模型系统提示词泄露项目爆火，反映出行业普遍在参考头部厂商的Prompt设计、模型对齐思路，来优化自有模型和应用的效果。
4. **AI配套基础设施逐步完善**：出现了专门面向AI Agent并行工作流设计的Git管理工具（worktrunk），说明AI开发的工具链正在从通用开发者工具向AI专属工具演进。
5. **数字访问自主权需求上升**：侧载工具、流媒体自定义客户端、网络隧道类项目热度居高不下，反映出全球用户对摆脱平台内容限制、自主掌控访问权限的需求持续增长。
